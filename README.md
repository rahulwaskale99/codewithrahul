### `whoami`

I'm a **Java Backend Engineer** with 5+ years of experience building
enterprise backend applications and APIs.

Most of my time goes into **Java, Spring Boot, REST APIs, microservices,
databases, debugging, and production support**.

I enjoy the part of software engineering that usually happens after
the happy-path demo:

`Why did this fail?`
`Why is this API slow?`
`What happens if this service goes down?`
`Can we make this simpler?`

That's usually where the interesting engineering starts.

### `a little about how I work`

I like to understand the **business problem first**, then work backward
to the technical solution.

When something breaks, I prefer starting with evidence — logs, request
flow, database behavior, and actual symptoms — rather than guessing.

And if the solution can be made simpler without losing reliability,
that's usually the direction I prefer.
